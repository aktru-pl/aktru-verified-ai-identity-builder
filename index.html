AKTRU Verified AI Identity Builder

Traceable company identity from website and supplied evidence.

AKTRU Verified AI Identity Builder audits how a company is represented across website content, metadata, structured data and machine-readable files. An optional registry document supplied by the user can support comparisons, but the tool does not authenticate that document.

Selected files are processed locally in the browser and are not uploaded.
Technical analysis only — this tool is not a certificate and does not replace an official registry or human review.

Evidence classes

Supported by supplied registry document

The value is present in a registry document supplied by the user.

Declared by website owner

The value is explicitly present in website-controlled content.

Inferred from technical content

The value or state is derived from markup, URLs or technical relationships.

Unresolved

The available evidence is insufficient for a safer classification.

The tool confirms only that a value is present in the registry document supplied by the user. It does not independently verify the document’s origin, authenticity or current validity. A file hash identifies the exact analyzed bytes; it does not prove authenticity.

Basic workflow

  1. Select evidenceChoose a local website snapshot and optionally a registry JSON document.
  2. Audit identity signalsInspect metadata, structured data, resources and machine-readable files.
  3. Compare sourcesKeep technical consistency separate from supplied registry evidence coverage.
  4. Review fieldsA human explicitly approves every value included in a proposal.
  5. Export proposalsDownload reports and deterministic files without modifying the inputs.

Scope and documentation

The application has no backend, user account, database, telemetry or external analysis API. It does not certify a company, validate a registry document’s origin, guarantee indexing or promise visibility or ranking.
