# Security

AKTRU is a static browser application. Processing is local; there is no backend, telemetry, analytics, external API or server-side file storage. Selected files remain in memory for the browser session and are not uploaded.

The exported registry summary omits full registry values and the original document. Fixtures must never contain real registry documents or personal data.

To report a vulnerability privately, contact:

[aktru@aktru.pl](mailto:aktru@aktru.pl)

Do not include sensitive documents in an issue or public report.
