# Demo guide

Run `npm install` and `npm run dev`. No local project snapshot is required for the public demo.

## Grand Sal PL

Choose **Try this demo** on Grand Sal PL. Show the 86/100 technical score, seven machine-readable files and the strict JSON parsing issue caused by a byte order mark.

## Grand Sal EN

Open Grand Sal EN. Show English identity signals, multilingual consistency and the complete machine-readable bundle.

## MEBIN DE

Open MEBIN DE. Show that all seven identity files are missing while the website is not falsely described as unavailable.

## Local file analysis

Use **Choose website folder** or **Choose index.html or files**. Optionally select a registry JSON. The browser analyzes the files locally. Never use real registry documents during a public recording.

## Review and export

Explain source classes, approve proposed fields manually, then download the analysis, before/after manifest or safe ZIP. The original registry document is not exported.
