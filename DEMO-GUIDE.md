# Demo guide

Open the [live demo](https://aktru-pl.github.io/aktru-verified-ai-identity-builder/) or run `npm ci` and `npm run dev`. No local project snapshot is required for the public demo.

Demonstration data is synthetic or anonymized and does not represent a current audit of a named business.

## Hospitality Demo PL

Choose **Try this demo** on Hospitality Demo PL. Show the 86/100 technical score, seven machine-readable files and the strict JSON parsing issue caused by a byte order mark.

## Hospitality Demo EN

Open Hospitality Demo EN. Show English identity signals, multilingual consistency and the complete machine-readable bundle.

## Furniture Demo DE

Open Furniture Demo DE. Show that all seven identity files are missing while the website is not falsely described as unavailable.

## Local file analysis

Use **Choose website folder** or **Choose index.html or files**. Optionally select a registry JSON. The browser analyzes the files locally. Never use real registry documents during a public recording.

## Review and export

Explain source classes, including that “Supported by supplied registry document” means presence in the user-supplied file only and does not authenticate it. Approve proposed fields manually, then download the analysis, before/after manifest or safe ZIP. The original registry document is not exported.
